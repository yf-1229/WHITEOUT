# WHITEOUT — Drone Rescue VR

Quest 2 / Quest 3S向けの雪山ドローン救助ゲームです。現在のXR解像度を維持したまま、機体を傾けて推力を作る飛行モデル、突風、雪山の空と景観を楽しみながら、1話約3〜5分・全24話の物語ミッションへ貢献できます。

## 起動

1. Unity 6 (`6000.0.66f2` 以降)でこのフォルダを開く。
2. Package Managerの解決を待ち、`Assets/Scenes/Prototype.unity`をPlayする。Gameビューは常に操縦者視点から始まり、ヘッドセットなしでもキーボードで確認できる。
3. Quest向けのOpenXR、Meta Quest Support、Quest 2 / 3Sのコントローラープロファイルは設定済み。

## ゲーム

物資輸送、静止スキャン、通信中継、救助地点の標識設置を組み合わせた短編救助シーズンです。各話は二つの航法地点、現地作業、基地帰還で構成され、初見で約3〜5分を想定しています。航路によって変わる局所風、話ごとの特殊条件、任意の割り込み救助が操縦判断に影響します。

- 起動直後：フリーフライト。`X / 2`で次話、右スティック押し込み / `3`で前話、`A / 1`で開始
- 全24話：`WHITEOUT`から`FIRST LIGHT`まで。クリアするたび次話が解放され、クリア済みの話はいつでも再出動できる
- 進行：航法地点1 → 航法地点2 → 現地作業 → 基地へ帰還・着陸
- 一部の話では航法地点1の通過後に救難信号が入り、8秒以内に救助へ向かうか本来の任務を続けるか選択。受諾後は現場上空で3秒間の低速ホバリングが必要
- 尾根の乱流、湖上の横風、建物付近の風下など、飛ぶ場所と高度で風が変化
- 各話に接近する嵐、消耗した電池、航法妨害、突風のいずれかを設定
- 現在の航法地点・作業地点・帰還パッドだけが脈動し、景色の中から目標を識別できる
- 物資投下は5m以内・低速・水平姿勢、標識設置は5m以内・低速が必要。設置した標識は発光ビーコンとして帰還中も現場に残り、スキャンでは任務地点固有の熱源をサーマルで捕捉できる
- 各話ごとに物語の結末、スコア、グレード、ローカルベストを保存
- 各話のベスト結果、操縦スタイル、割り込み救助が「救助ネットワーク」進捗へ反映され、復旧した地点の照明が強くなる

雪山はUnity Terrain APIで毎回同じ地形を生成し、標高・斜面・卓越風に応じて新雪、青い風成雪、露岩を混合します。低地の草、雪を被った針葉樹、岩場、氷の亀裂、暖かな山小屋、坑道木枠、気象パラボラ、視界と風に連動する吹雪も実行時生成です。全24話は4章で構成され、孤立した青い吹雪から夜明けの暖色へ、空・太陽・霧が物語とともに変化します。

## 操作

- Quest：左スティック＝高度／スロットル・ヨー、右スティック＝アシスト時は進行方向、マニュアル時はピッチ・ロール
- `A / 1`：選択中のストーリー開始／結果画面で再出動／任務中の救難信号を受諾
- `X / 2`：メニューで次話／任務中は2秒以内に2回押して中止／成功後に次話へ
- 右スティック押し込み / `3`：メニューで前話
- `Y / M`：アシスト／マニュアル切替（フリーフライト中）
- 右トリガー / `Space`：物資投下、スキャン確定、標識設置
- 右グリップ / `C`：操縦者 → フルFPV → 三人称追従
- `B / R`：自動帰還・着陸。着陸後は離陸
- キーボード操縦：左 `Q/E/A/D`、右 `W/S/J/L`

アシストでは高度を維持しつつスティック方向へバンクし、マニュアルではモーターの立ち上がりを含むスロットルと姿勢を直接操作します。微操作にはデッドゾーンと指数カーブを用い、中心付近は精密、倒し切ると素早く反応します。電池消費、モーター音、風音は速度・昇降操作・局所風に追従し、危険な気流、低高度降下、接触は音と右コントローラーの振動でも伝わります。救難・失敗・達成には短い無線音を使います。HUDはFPVゴーグルを参考に、中央の姿勢線と照準、速度・対地高度・電池のバー、風向・目標方向の矢印へ整理し、警告は必要な時だけ表示します。選択画面では各話のクリア状況、ベストスコア、救助ネットワーク進捗も確認できます。

実機ビルドとVR確認は [DEV.md](DEV.md) を参照してください。

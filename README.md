# WHITEOUT — Drone Rescue VR

Quest 2向けの雪山ドローン救助ゲームです。起動直後から自由に飛び、機内HUDのメニューから物語ミッションを開始できます。

## 起動

1. Unity 6 (`6000.0.66f2` 以降)でこのフォルダを開く。
2. Package Managerの解決を待ち、`Assets/Scenes/Prototype.unity`をPlayする。
3. QuestではAndroidのOpenXRとOculus Touch Controller Profileを有効にする。

## ゲーム

雪崩で道路が閉ざされ、暖房を失った山岳救護所に親子と救助隊が取り残されています。医療ドローンで血液と保温剤を積み、吹雪の峠を越えて物資を投下し、基地へ帰還してください。

- 起動直後：フリーフライト。HUD左上のメニューから `A / 1` で「WHITEOUT」を開始
- 第1段階：青い雪崩監視ビーコンを通過
- 第2段階：尾根の赤い救難信号へ接近し、4m以内で物資を投下
- 第3段階：基地へ帰還・着陸。時間、接触、バッテリーから救援スコアを算出

雪山はUnity Terrain APIで毎回同じ地形を生成し、標高・斜面に応じて雪と岩を混合します。低地の草、雪を被った針葉樹、岩場、視界と風に連動する吹雪も実行時生成です。

## 操作

- Quest：左スティック＝高度・ヨー、右スティック＝前後・左右
- `A / 1`：メニューでストーリー開始／結果画面で再出動
- `X / 2`：結果画面からフリーフライトへ戻る
- `Y / M`：アシスト／マニュアル切替（フリーフライト中）
- 右トリガー / `Space`：医療物資を投下
- 右グリップ / `C`：操縦者 → フルFPV → 三人称追従
- `B / R`：自動帰還・着陸。着陸後は離陸
- キーボード操縦：左 `Q/E/A/D`、右 `W/S/J/L`

HUDはFPVゴーグルを参考に、方位、対地速度、高度、昇降速度、電池、映像リンク、風、目標距離、姿勢線を常時表示します。

実機ビルドとVR確認は [DEV.md](DEV.md) を参照してください。

# WHITEOUT — Drone Rescue VR

Quest 2 / Quest 3S向けの雪山ドローン救助ゲームです。現在のXR解像度を維持したまま、機体を傾けて推力を作る飛行モデル、突風、雪山の空と景観を楽しみながら、全24話の状況任務へ出動できます。

## 起動

1. Unity 6 (`6000.0.66f2` 以降)でこのフォルダを開く。
2. Package Managerの解決を待ち、`Assets/Scenes/Prototype.unity`をPlayする。Gameビューは常に操縦者視点から始まり、ヘッドセットなしでもキーボードで確認できる。
3. Quest向けのOpenXR、Meta Quest Support、Quest 2 / 3Sのコントローラープロファイルは設定済み。

## ゲーム

物資輸送、静止スキャン、通信中継、救助地点の標識設置を組み合わせた短編救助シーズンです。各話は二つの航法地点、現地作業、基地帰還で構成され、初見で約3〜5分を想定しています。航路によって変わる局所風、話ごとの特殊条件、任意の割り込み救助が操縦判断に影響します。

- 起動直後：`START FLIGHT`、`PRACTICE RANGE`、`SETTINGS`のTOPメニュー。練習場は進行を変えずに基地周辺を飛べる
- 全24話：`WHITEOUT`から`FIRST LIGHT`まで。クリアするたび次話が解放され、クリア済みの話はいつでも再出動できる
- 進行：航法地点1 → 航法地点2 → 現地作業 → 基地へ帰還・着陸
- 一部の話では航法地点1の通過後に救難信号が入り、8秒以内に救助へ向かうか本来の任務を続けるか選択。救難地点には遭難者と緊急毛布が現れ、受諾後はその上空で3秒間の低速ホバリングが必要
- 尾根の乱流、湖上の横風、建物付近の風下など、飛ぶ場所と高度で風が変化
- 各話に接近する嵐、消耗した電池、航法妨害、突風のいずれかを設定
- 現在の航法地点・作業地点・帰還パッドだけが脈動し、景色の中から目標を識別できる
- 物資投下は5m以内・低速・水平姿勢、標識設置は5m以内・低速が必要。目標へ接近すると中央インジケータが安定化不足か実行可能かを示す。設置した標識は発光ビーコンとして帰還中も現場に残る。スキャンは寒色へ切り替わるサーマル映像で橙色の熱源を捕捉し、静止保持中だけ中央の細ゲージが進む
- 各話ごとに現地の変化、スコア、グレード、ローカルベストを保存
- 各話のベスト結果、操縦スタイル、割り込み救助が「救助ネットワーク」進捗へ反映。救護所・森林小屋を対象にした任務を初めて成功させると、暗かった現地の窓が恒久的に灯る

雪山はUnity Terrain APIで毎回同じ地形を生成し、標高・斜面・卓越風に応じて新雪、青い風成雪、露岩を混合します。奥行きを持つ低ポリゴン遠景山地は面の向きと傾斜ごとに雪の明部・青い陰・露岩を描き分け、雪面の影も灰黒く潰さず冷たい青で残し、幹・枝葉・雪冠を1メッシュにまとめた針葉樹林とともに遠近を作ります。基地から救護所へ続く二本の雪上救助トラックが、広い雪原に奥行きと生活の痕跡を加えます。吹雪が強まると遠景から霧へ消えます。針葉樹には軽量な衝突形状があり、森林の低空航行では枝葉を避ける操縦が必要です。低地の草、岩場、氷の亀裂、暖かな山小屋、坑道木枠、気象パラボラ、視界と風に連動する吹雪も実行時生成です。着陸地点は発光球ではなく、地形の傾斜へ沿って雪面に密着するマットなパッドと反射塗装で示し、誘導灯は目標地点だけを弱く照らします。空中航法点の高度はパッド模型から分離されています。全24話は4章で構成され、孤立した青い吹雪から夜明けの暖色へ、空・太陽・霧が任務の進行とともに変化します。

## 操作

- Quest：左スティック＝高度／スロットル・ヨー、右スティック＝アシスト時は進行方向、マニュアル時はピッチ・ロール
- `A / 1`：TOP・ミッション・設定メニューの選択／結果画面で再出動／任務中の救難信号を受諾
- `X / 2`：メニューの次項目／任務中は2秒以内に2回押して中止／成功後に次話へ
- 右スティック押し込み / `3`：メニューの前項目
- 飛行モード：`SETTINGS`またはミッション選択内の`FLIGHT`でアシスト／マニュアルを切替
- 右トリガー / `Space`：物資投下、スキャン確定、標識設置
- 右グリップ / `C`：操縦者 → フルFPV → 三人称追従
- `B / R`：地形を先読みして安全高度を保つ自動帰還・着陸。着陸後は離陸
- キーボード操縦：左 `Q/E/A/D`、右 `W/S/J/L`

アシストでは前進・後進バンク中もRigidbodyの実姿勢から上向き推力を補正して高度を維持し、強い旋回で深く倒れた場合はヨーを残して自動水平復帰します。マニュアルではモーターの立ち上がりを含むスロットルと、姿勢を自動復元しないFPVレート制御を直接操作します。再出動時は物理補間履歴を切り、機体と映像を必ず水平姿勢へ戻します。機首カメラは機体のピッチ・ロール・ヨーへ追従するため、バンクと推力方向を映像から読み取れます。微操作にはデッドゾーンと指数カーブを用い、中心付近は精密、倒し切ると素早く反応します。ローター回転とモーター音は、移動速度ではなく上昇・ホバリング・傾斜補正に必要な実推力へ即応します。自動帰還は24m先までTerrainを読み、少なくとも地上12mの余裕を保ってから着陸します。電池消費と風音は速度・昇降操作・局所風に追従し、危険な気流、低高度降下、接触は音と右コントローラーの振動でも伝わります。救難・失敗・達成には短い無線音を使い、現場の人物の動き、灯る窓、変わる天候で状況を伝えます。HUDはDJI FPVゴーグルの情報配置を参考に、映像中央を空け、速度・高度・電池・風・目標を画面端の小ラベル・大数値・細ゲージへ整理しています。中央は方向円と姿勢線、上端は方位、警告は必要な時だけ表示します。大型作戦カードは操縦者視点だけ、快適枠は三人称追従だけに表示し、フルFPVでは映像全面にOSDだけを重ねます。選択画面では各話のクリア状況、ベストスコア、救助ネットワーク進捗も確認できます。
